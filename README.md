# Лабораторная работа №5

Создание ресурсов (POST) в ASP.NET Web API

## Цель работы

Научиться:
- создавать новые ресурсы через API
- принимать данные от клиента в формате JSON
- сохранять данные в базе данных через EF Core
- возвращать корректные HTTP-ответы (201 Created)
- понимать REST-подход к созданию ресурсов

## Вариант задания

**2-умножение** 

## Выполнение работы

1. Создать DTO для входных данных (`CreateCalculationDto`)
2. Реализовать POST-метод создания ресурса
3. Сохранить данные в таблицу `Calculations`
4. Вернуть созданный ресурс клиенту 
5. Проверить работу через Postman
